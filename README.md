# Green Cares Specialists — Official Website

> **Residential Home Renovation & Wet Works Specialists**  
> Eco Forest HQ, Semenyih · Serving Semenyih, Kajang, Bangi, Cheras, PJ, KL & wider Selangor.

A modern, high-performance web platform built with **React**, **Vite**, **Sass (SCSS)**, and **React Router DOM**, designed specifically for residential property owners seeking quality craftsmanship, transparent itemized BOQs, and zero shortcuts.

---

## 🌟 Core Features & Pages

- **Full-Width Architectural Hero**: Showcases commercial-grade durability benchmark (C2 Coffee + Candle) applied to residential renovation, with 3 core trust pillars (**Itemized BOQ**, **Direct Supervision**, **Workmanship Warranty**).
- **Residential Services (`/services`)**: In-depth scopes for Landed House Extensions & Wet Kitchens, Condo Fit-Outs, Waterproofing & Leak Prevention (with mandatory 72-hr ponding test), and Custom Carpentry & M&E rewiring.
- **Site Workmanship & Proof of Execution (`/workmanship`)**: Transparent on-site photo logs, defect liability standards, and the C2 Coffee + Candle flagship handover case study.
- **5-Step Renovation Process (`/process`)**: Milestone roadmap from on-site measurement and line-by-line BOQ to handover inspection and defect warranty.
- **Interactive Cost Estimator (`/calculator`)**: Real-time property-type and scope-based renovation budget calculator tailored for Malaysian homeowners.
- **Contact & Regional Coverage (`/contact`)**: Instant quotation request, Semenyih HQ office details, and direct messaging channel.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: Pure Sass / SCSS (Custom responsive grid, design system variables & mixins)
- **Routing**: `react-router-dom` (Multi-page client-side routing)
- **Icons**: `lucide-react`
- **Typography**: Plus Jakarta Sans

## 🚀 Getting Started

### 1. Installation
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 3. Production Build
```bash
npm run build
```
Optimized static files will be generated in the `dist/` directory.

### 4. Preview Production Build
```bash
npm run preview
```
